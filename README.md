# Delytra

Delytra is an AI-powered platform I'm building to make DSA practice and technical interview preparation more personalized.

The idea is simple: instead of solving random coding problems, Delytra keeps track of how you perform, identifies the areas where you struggle, and uses that information to suggest what you should work on next.

## What I'm Building

- **DSA Problem Library**  
  Browse and practice coding problems based on difficulty and topic.

- **Online Code Execution**  
  Write and run code directly on the platform with support for multiple programming languages.

- **AI Code Review**  
  Get feedback on your approach, code quality, time complexity, space complexity, and possible improvements.

- **Personalized Recommendations**  
  Problems are recommended based on your previous submissions, solved problems, and weaker topics.

- **Progress Tracking**  
  Track solved problems, attempts, performance, and improvement over time.

- **AI Interview Preparation**  
  A future part of the project will include AI-powered mock technical interviews that adapt to the user's performance.

Why I’m Building It

I wanted to build something that combines the things I’m currently learning — backend development, frontend development, databases, authentication, AI integration, and DSA — into one practical project.

Rather than making another simple CRUD application, Delytra is my attempt to build something that I would actually want to use while preparing for technical interviews.
